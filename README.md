## Selected work

### 01 / Euro Suits ERP
**A connected workspace for garment manufacturing.**

Enquiry, costing, approvals, production planning, material management, and finance workflows in one application.

- **Application:** SvelteKit and TypeScript frontend with a Go API.
- **Data & operations:** PostgreSQL migrations, Redis, background jobs, Docker Compose, and Nginx configuration.
- **Engineering depth:** Scoped permissions, audit tooling, integration tests, and workflow regression test source.

[Explore the source →](https://github.com/ansu9932/euro-suits-erp-full-project)

<sub>The public repository is a source snapshot, separate from the private production deployment. Feature and verification boundaries are documented in its README.</sub>

### 02 / Family Compass
**Mobile apps connected through a consent-based internet relay.**

A Flutter project spanning an iPhone parent app, Android child app, native integrations, and a Python/AWS relay.

- **Cross-platform work:** Flutter/Dart with Android and iOS integrations and WebRTC.
- **Sharing controls:** Visible, stoppable media sharing and Android screen-capture approval.
- **Privacy choices:** Opt-in notification activity limited to app names and arrival times, without message contents.

[Explore the source →](https://github.com/ansu9932/family-compass)

<sub>Build requirements, platform limitations, and verification status are documented in the repository.</sub>
